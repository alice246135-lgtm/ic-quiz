對數報酬率 P11

Rt+h = ln( St+h / St )S 是收盤價，h 是持有月數。課程使用 h = 1。

使用對數報酬而不用簡單報酬，是因為它具可加性、不受基期影響、漲跌幅對稱。

例：100 → 200 → 100。簡單報酬 +100% 和 −50% 相加得 +50%，是錯的；對數報酬 ln2 + ln0.5 = 0，正確反映回到原點。

資訊係數 IC P18–20

ICt = corr( Xt, Rt+1 )本期因子值和「下一期」報酬的相關係數。課程用 Normal IC，h = 1。
  • 範圍 −1 ~ 1
  • IC > 0：因子越高，下期報酬傾向越高
  • IC < 0：因子越高，下期報酬傾向越低
  • |IC| 越大，預測力越強；接近 0 代表幾乎沒有預測力

策略步驟 P21–25

  1. 算下期報酬和 3 個因子值
  2. 每月算歷史 IC，每個因子一條 IC 序列
  3. 站在 2013/12，用 2013/11 以前資料預測 IC
  4. 選 |預測 IC| 最大的因子
  5. 依 IC 正負決定買賣方向
  6. 依因子值分 N 等份建組合
  7. 算 2014/01 報酬，和台灣指數比較
預測 IC策略買賣（放空）
正買高賣低因子最高的等份（優勢組）因子最低的等份
負買低賣高因子最低的等份因子最高的等份

3 種投資組合：多空（買高賣低或買低賣高）、只買優勢組、只買劣勢組。

多空報酬 = 買進組平均報酬 − 放空組平均報酬例：選到 size，IC = −0.07 → 買小賣大。小公司組 +1%、大公司組 −2% → 報酬 +3%，大盤 −3%，打敗大盤。

台灣指數也要用月收盤價自己算對數報酬，算法一致才能比較。

延伸分析

  • 比較 13 種等份：等份越多，每組股票越少、越極端，報酬可能更高但波動更大
  • 把預測期間拉長到 2014/01 起的多個月：增加樣本，看勝率和穩定性
  • 換其他模型：XGBoost、雙向 LSTM、Bayes、PLS、PCR、ENet、GLM、GBRT

Excel 資料處理 P26–30

變數計算

變數公式
下個月月報酬=IFERROR(LN(收盤價!D2/收盤價!C2),"缺值")
size=IFERROR(LOG(市值!C2*1000000),"缺值")
bm=IFERROR(1/股價淨值比!C2,"缺值")
mom（O2 格）=IFERROR(LN(收盤價!N2/收盤價!C2),"缺值")
2000/01 的動能 = 1999/12 股價 ÷ 1999/01 股價

處理流程

  • 合併：XLOOKUP(查找值, 查找範圍, 回傳範圍, FALSE)，FALSE 是完全相符，範圍要加 $ 固定
  • 存活公司：用 COUNT 數 2013/12 ~ 2026/08 有幾個月有值，不是 153 個月的公司刪除
  • 補值：因子或報酬其中一個是「缺值」，兩邊都用該月中位數補
  • 算 IC：=CORREL(size_補值!C$2:C$1443, 下個月月報酬_補值!C$2:C$1443)

快捷鍵：Ctrl+A 全選；Ctrl+Shift+↓ 選到底；Ctrl+↑ 回頂部。

預測模型：OLS 線性迴歸 P32–38

未來報酬 = 觀察得到的部分（模型可以預測）+ 觀察不到的部分（誤差）。

ICt+1 = α + β·Xt + ε用訓練集估出 α、β，再代入最新的 X 預測下一期 IC。
bm、size 訓練集 X: 1999/01 ─ 2013/10 IC: 1999/02 ─ 2013/11 mom 訓練集 X: 2000/01 ─ 2013/10 IC: 2000/02 ─ 2013/11 測試集 代入 X(2013/11) → 預測 IC(2013/12) → 用來決定 2014/01 的持股

為什麼站在 2013/12 算不出真實 IC(2013/12)？因為它需要 2013/12 → 2014/01 的報酬，當下還沒發生。

為什麼 mom 從 2000/01 開始？動能要用過去 12 個月股價，股價從 1999/01 開始，最早到 2000/01 才湊得滿。

常考觀念

觀念重點
前視偏誤用了決策當下還不知道的資料，例如用 2013/12 以後的資料預測 2013/12 的 IC。回測會好得不真實。
存活者偏誤只留全期存活的公司，下市的爛公司被排除，結果可能被高估。課程為了資料完整而接受這個取捨。
訓練集 vs 測試集訓練集用來估參數；測試集用模型沒看過的資料檢驗預測力。只看訓練集表現會過度樂觀（過度配適）。
中位數補值中位數不受極端值影響，補上去也比較不會扭曲相關係數。
多空組合賺兩組的相對表現，可以降低大盤漲跌的影響。大盤大跌時仍可能賺錢。
方向押錯預測 IC 為正、實際為負時，買高賣低會虧損。
單月結果只有一個月打敗大盤可能是運氣，要看多個月的勝率和穩定性。
AI 模型RF、NN 能捕捉非線性關係，但不保證一定比 OLS 準，要實際比較。
